## چه کارهایی می‌کنه؟

- ⚡ **ترمینال زنده** — یک نشست واقعی SSH که توی یک پیام زنده به‌روز می‌شه. هر چی بفرستی تایپ می‌شه؛ دکمه‌های Ctrl+C، Tab، جهت‌ها و صفحه‌ی کلیدهای ویرایشگر (Ctrl+X/O، Home/End، PgUp/PgDn) برای `nano`، `less` و `htop` هم هست.
- 📁 **فایل‌ها (SFTP)** — مرور، دانلود (تا ۵۰ مگ)، آپلود (تا ۲۰ مگ)، ساخت پوشه و حذف.
- 📊 **مانیتور** — CPU، رم، swap، دیسک، آپتایم، لود، کانتینرهای داکر، سرویس‌های خراب و پرمصرف‌ترین پردازش‌ها.
- 🧰 **ابزارها** — پردازش‌ها، پورت‌های باز، دیسک، داکر، سرویس‌های خراب، آخرین خطاها، ورودها و آپدیت‌های در انتظار با یک لمس؛ به‌علاوه ری‌استارت با تأیید.
- 🔔 **اعلان قطعی** — برای هر سرور 🔔 رو روشن کن تا اگه از دسترس خارج شد (و دوباره وصل شد) همین‌جا خبرت کنه.
- 🏠 **همین سرور** — اختیاری و فقط برای ادمین: مدیریت ماشینی که خودِ ربات روش اجرا می‌شه.
- 💎 **حالت عمومی یا اشتراکی** — برای خودت یا تیمت اجراش کن، یا اشتراک بفروش: روز و سقف سرور با آیدی عددی، هشدار پایان اشتراک، جوین اجباری و پیام همگانی.
- 💾 **بکاپ رمزگذاری‌شده** — هر روز خودکار برای ادمین می‌آد و روی سرور جدید با یک فایل ریستور می‌شه.
- 🌐 **فارسی و انگلیسی** — تغییر زبان برای هر کاربر.

سبکه: حدود ۱۰۰ تا ۲۰۰ مگابایت رم، بدون دیتابیس جدا، بدون پورت باز.

## نصب

یک سرور لینوکس (ترجیحاً Debian/Ubuntu)، دسترسی root، توکن ربات از [@BotFather](https://t.me/BotFather) و آیدی عددی تلگرامت لازمه.

</div>

```bash
curl -fsSL https://raw.githubusercontent.com/AtronixX-Core-98/AtronixX-ServerManager/main/install.sh | sudo bash
```

<div dir="rtl">

نصاب سیستم رو بررسی می‌کنه، اگه لازم باشه Docker رو نصب می‌کنه، توکن رو با تلگرام اعتبارسنجی می‌کنه، `.env` خصوصی می‌سازه، ایمیج رو می‌گیره (یا اگه نبود از سورس می‌سازه)، ربات رو بالا می‌آره و صبر می‌کنه آنلاین بشه. بعدش ربات رو باز کن و `/start` بفرست.

### دستور `AX-Manager`

بعد از نصب، `sudo AX-Manager` پنل کنترل رو باز می‌کنه. دستورهای دیگه:

</div>

```
AX-Manager status          وضعیت، آپتایم، کاربران، رم
AX-Manager doctor          بررسی سلامت و توضیح مشکل‌ها
AX-Manager logs -f         دنبال‌کردن لاگ
AX-Manager update          آپدیت (اول از داده‌ها بکاپ می‌گیره)
AX-Manager settings        تغییر توکن، ادمین، نام، منطقه‌ی زمانی، شبکه‌های مجاز
AX-Manager host-access     enable | disable | status | test
AX-Manager backup          بکاپ محلی tar.gz
AX-Manager import-data D   وارد کردن تنظیمات و داده از یک پوشه‌ی نصب دیگه
AX-Manager uninstall
```

## دسترسی به «همین سرور»

به **تو (ادمین)** اجازه می‌ده روی ماشینی که ربات روش اجرا می‌شه ترمینال باز کنی، فایل‌ها رو ببینی، مانیتور و ابزارها رو بزنی — کاری که یه کانتینر معمولاً نمی‌تونه.

</div>

```bash
sudo AX-Manager host-access enable
```

<div dir="rtl">

چی راه می‌اندازه: یک کلید اختصاصی ed25519 توی `data/host_key`؛ یک ورودی `authorized_keys` با محدودیت `from="<شبکه‌ی ربات>",restrict,pty` تا کلید از هیچ جای دیگه‌ای کار نکنه؛ قانون فایروال برای شبکه‌ی خصوصی ربات (اگه `ufw` فعال باشه)؛ و پین‌کردن کلیدهای SSH سرور توی `.env` تا ربات با یه سرور جعلی حرف نزنه.
**به‌صورت پیش‌فرض خاموشه**، **فقط برای ادمین** نمایش داده می‌شه و با `host-access disable` هر وقت خواستی خاموش می‌شه.

> ⚠️ این قابلیت کنترل کامل سرور رو به حساب تلگرام ادمین می‌ده. حتماً تأیید دومرحله‌ای تلگرام رو روشن کن.

## تنظیمات

همه‌چیز توی `/opt/servermanager/.env` هست (نمونه: [`.env.example`](.env.example)):

- `BOT_TOKEN`، `ADMIN_ID` — الزامی.
- `BACKUP_PASSPHRASE` — رمز فایل‌های بکاپ (حداقل ۸ کاراکتر؛ جای امنی نگهش دار).
- `BOT_NAME` — اسمی که توی پیام‌ها نشون داده می‌شه. `SUPPORT_USERNAME` — اگه پر باشه دکمه‌ی «پشتیبانی» نشون داده می‌شه.
- `MAX_LIVE_SESSIONS`، `IDLE_TIMEOUT_MIN`، `MAX_SESSION_HOURS` — محدودیت نشست‌ها.
- `WATCH_INTERVAL_MIN`، `MAX_WATCH_PER_USER` — اعلان قطعی.
- `BLOCKED_IPS` — آدرس‌هایی که کاربرها هیچ‌وقت نباید بهشون وصل بشن (نصاب IPهای عمومی همین سرور رو اضافه می‌کنه).
- `ALLOWED_NETS` — شبکه‌های خصوصی که کاربرها **اجازه** دارن بهشون وصل بشن (شبکه‌ی داخلی/VPN)، مثل `10.8.0.0/24,100.64.0.0/10`.

به‌صورت پیش‌فرض فقط اتصال به آدرس‌های **عمومی** ممکنه؛ آدرس‌های لوکال، لینک‌لوکال (متادیتای ابری)، خصوصی و رزرو شده رد می‌شن.

## بکاپ و جابه‌جایی سرور

بکاپ یک فایل رمزگذاری‌شده‌ی `.smbak` (دیتابیس + کلید اصلی) هست که خودکار برای ادمین می‌آد. برای ریستور روی سرور جدید: نصب کن، بعد فایل رو توی **پنل ادمین ← بکاپ و ریستور ← ریستور** برای ربات بفرست و رمز بکاپ رو بده.

## ارتقا از نسخه‌ی پیش‌انتشار

`AX-Manager import-data /path/to/old/install` رو اجرا کن. دیتابیس، اطلاعات رمزشده و بکاپ‌های قدیمی همچنان کار می‌کنن (`core/legacy_v1.py`؛ اگه هیچ‌وقت نسخه‌ی پیش‌انتشار رو نداشتی می‌تونی حذفش کنی).

## امنیت

[SECURITY.md](SECURITY.md) رو ببین. خلاصه: رمزنگاری AES-256-GCM، حذف خودکار پیام‌های حاوی رمز، تأیید کلید سرور، جلوگیری از SSRF، کانتینر بدون دسترسی ویژه و فقط‌خواندنی — و یک محدودیت صادقانه: هر کسی که سرور ربات رو در اختیار داره از نظر فنی می‌تونه اطلاعات ذخیره‌شده رو بخونه.
